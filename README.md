## Description
Checkers Game is a browser-based board game built with HTML, CSS, and JavaScript. It supports two players sharing one device and a single-player mode against a basic computer opponent. The interface uses a modern dark theme.

## Features
- 8×8 checkers board
- Local two-player mode
- Computer opponent with Easy, Medium, and Hard settings
- Legal diagonal moves and mandatory captures
- Multi-jump captures
- King promotion
- Win detection
- Legal-move hints, undo, board flip, and restart controls
- Responsive layout for desktop and mobile screens

## How to Run
1. Download or clone this repository.
2. Open the `checkers-game` folder.
3. Double-click `index.html` to open it in a modern browser.
4. Choose a game mode and start playing.

No package installation or build step is required.

## Rules and Limitations
This project follows a simplified American-checkers ruleset: pieces move diagonally on dark squares, captures are mandatory, and kings can move and capture in both directions. The computer opponent uses a basic search strategy and is not a tournament-level engine. In this starter version, multi-jump sequences are supported.
